# Ուսում · Կայուն զարգացում

Աշխատող հայերեն ուսումնական MVP՝ կազմված կից «Թեմա 8» ներկայացման և ընթերցանության նյութի հիման վրա։ Այն ներառում է հոսքային ծառայության ոճով դասընթացների էջ, հինգ ուսումնական բաժին, ՄԱԿ-ի 17 նպատակների բովանդակություն, ինքնաստուգման թեստ, բաց պատասխանի գնահատում, նյութի վրա հիմնված հարցուպատասխան, դիտարկիչում պահվող առաջընթաց և Articulate Storyline-ի SCORM 1.2 / 2004 ZIP փաթեթների ներբեռնում։

## Բացել ցուցադրական տարբերակը

Բացեք `index.html` ֆայլը՝ կրկնակի սեղմումով։ Դասը, տեղային առաջընթացը, թեստը, Q&A-ն և բաց պատասխանի ցուցադրական գնահատումը աշխատում են առանց սերվերի կամ փաթեթներ տեղադրելու։

## Գործարկել սերվերը

Գործարկեք `start.bat` ֆայլը։ Այն կօգտագործի համակարգում կամ Codex միջավայրում առկա Node.js-ը։ Այլ կերպ՝ այս թղթապանակում գործարկեք `node server.js`, ապա բացեք [http://localhost:3000](http://localhost:3000)։ Արտաքին փաթեթներ տեղադրելու կարիք չկա։ Սերվերը պետք է, որ աշխատեն SCORM ZIP վերբեռնումը և սերվերային AI API-ն։

## Հրապարակել ինտերնետում

Այս թղթապանակն ունի Dockerfile՝ Node.js հոսթինգում տեղակայելու համար։ Հոսթինգը պետք է աջակցի Docker-ին, մշտական պահոց (առնվազն 1 ԳԲ՝ SCORM դասընթացների համար), `PORT`, `HOST`, `DATA_DIR` և `UPLOAD_TOKEN` միջավայրի փոփոխականներին, ինչպես նաև առնվազն 400 ՄԲ HTTP վերբեռնմանը։ Միացրեք պահոցը `/data` հասցեին. SCORM փաթեթներն ու ցանկը պահպանվում են այնտեղ՝ վերագործարկումների միջև։

Տեղակայման միջավայրում սահմանեք `UPLOAD_TOKEN`-ը՝ որպես մասնավոր գաղտնի արժեք, և մի հրապարակեք այն սովորողներին։ Հոսթինգի տրամադրած HTTPS հասցեն կարելի է ուղարկել սովորողներին։ Տեղակայելուց հետո մուտք գործեք դասընթացի էջ և վերբեռնեք SCORM ZIP-ը. տեղային `data/` թղթապանակը Docker պատկերում չի ներառվում։ Առանց օգտահաշիվների բոլոր այցելուները կիսում են նույն հրապարակային դասընթացի էջը, իսկ յուրաքանչյուր սովորողի առաջընթացը պահվում է իր դիտարկչում։

## AI հնարավորությունները միացնել

Առանց բանալու հարցուպատասխանը և բաց պատասխանի գնահատումը աշխատում են դասանյութի վրա հիմնված ցուցադրական կանոններով։ Եթե ունեք OpenAI API հաշիվ և ցանկանում եք միացնել մոդելի պատասխանները, այս թղթապանակում ստեղծեք `.env.local` ֆայլ՝

```text
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4o
```

Վերագործարկեք սերվերը։ Բանալին մնում է սերվերում և չի ուղարկվում դիտարկչին։ AI ռեժիմում սովորողի հարցերն ու բաց պատասխանները ուղարկվում են OpenAI API՝ գնահատման համար։ API օգտագործումը կարող է վճարովի լինել։ Մի հրապարակեք բանալին կամ `.env.local` ֆայլը։

## Storyline դասընթաց ավելացնել

Արտահանեք Articulate Storyline դասընթացը որպես SCORM 1.2 կամ SCORM 2004 ZIP՝ ներառելով `imsmanifest.xml`։ Գլխավոր էջում ընտրեք «Փաթեթ ավելացնել»։ Եթե սերվերի ադմինը կարգավորել է `UPLOAD_TOKEN`, ներբեռնման պատուհանում մուտքագրեք տրամադրված գաղտնաբառը։ Վերբեռնումից հետո դասընթացը բացվում է SCORM API-ով ապահովված iframe-ում։

## Տվյալներ և սահմանափակումներ

- Դասընթացի ընթացիկ առաջընթացը և պատասխանները պահվում են սովորողի դիտարկչի `localStorage`-ում։ Սերվերի կենտրոնական մատյան, օգտահաշիվներ և վճարումներ այս MVP-ում չկան։
- Կից ֆայլերում Storyline SCORM փաթեթ չկար, ուստի հիմնական դասընթացը կառուցված է տրամադրված սլայդների և ընթերցանության տեքստի հիման վրա։ Ներկայացման մեջ եղած տեսանյութերի հղումները բացվում են YouTube-ում։
- Առանց `OPENAI_API_KEY`-ի օգնականը չի կանչում գեներատիվ AI․ այն տալիս է նախապես կազմված, դասընթացի թեմաներին համապատասխան պատասխաններ։ Տեղային բաց պատասխանի գնահատումը ցուցադրական, բառային համապատասխանության վրա հիմնված գնահատում է, ոչ թե ակադեմիական հաստատված գնահատական։
- SCORM ընդունողը MVP է և չի ապահովում ամբողջական SCORM համապատասխանություն կամ SCORM-ի առաջընթացի կենտրոնական ամպային պահպանում։ Հրապարակային տեղակայման դեպքում սահմանեք `UPLOAD_TOKEN`, օգտագործեք HTTPS և persistent storage ունեցող հոսթինգ։

Մուտքեր, վճարումներ և հավաստագրեր դիտավորյալ թողնված են հետագա փուլերին՝ ըստ կից ծախսային առաջարկի։
